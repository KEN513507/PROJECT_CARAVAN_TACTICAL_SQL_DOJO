# NEON RELAY 手動UXテスト手順書（20分版）

改修（オープニング＋チュートリアル追加）前のベースラインを人間の手で確認するための手順書です。
AIによる自動テストではなく、実際に指でタップ・クリックして確認します。
専門知識がなくても実施できるように、「何をタップするか」「何が見えるべきか」「なぜ確認するのか」を1項目ごとに書いています。

結果は [`MANUAL_UX_TEST_RESULT.md`](./MANUAL_UX_TEST_RESULT.md) に記入してください。

---

## 0. 準備（2分）

### 0-1. サーバーを起動する

プロジェクトのフォルダで、以下のコマンドを実行します（PowerShellまたはターミナル）。

```
python -m http.server 8000 --bind 0.0.0.0
```

- `--bind 0.0.0.0` をつけることで、同じWi-Fiに繋がっているiPhoneからもアクセスできるようになります。
- 起動したまま、テストが終わるまでこのウィンドウは閉じないでください。

### 0-2. アクセスするURLを確認する

| 端末 | URL |
|---|---|
| PC | `http://127.0.0.1:8000/` |
| iPhone | `http://<PCのIPアドレス>:8000/` |

PCのIPアドレスがわからない場合は、別のPowerShellウィンドウで以下を実行し、`IPv4 アドレス` の欄（例: `192.168.1.23`）を確認してください。

```
ipconfig
```

iPhoneとPCが **同じWi-Fiネットワーク** に接続されていることを確認してください（別ネットワークだと繋がりません）。

### 0-3. PCでF12コンソールを開く手順

1. PCのブラウザ（Chrome推奨）でゲームのURLを開く
2. キーボードの `F12` キーを押す（または画面を右クリック →「検証」）
3. 開いたパネル上部のタブから **「Console」** を選ぶ
4. 赤字の「Error」が出ていないか、このあと各項目を実施するたびに目で確認する

### 0-4. 所要時間の目安

| セクション | 時間 |
|---|---|
| 0. 準備 | 2分 |
| 1. PCセクション | 8分 |
| 2. iPhoneセクション | 8分 |
| 3. エッジケースセクション | 4分（ゆとり込み） |
| **合計** | **約20分** |

## 2. iPhoneセクション（8分・8項目）

iPhoneの実機（Safari推奨）で、PCと同じCHAPTER 1を実施します。
**iPhoneのブラウザは事前にキャッシュを消しておいてください**（Safari設定 → 履歴とWebサイトデータを消去）。

### CHAPTER 1をiPhoneで再実施

| # | 何をタップするか | 何が見えるべきか（期待値） | なぜ確認するのか |
|---|---|---|---|
| i-1 | iPhoneのSafariで `http://<PCのIPアドレス>:8000/` を開く | PCと同じCHAPTER 1の画面が表示される（文字や画像が崩れていない） | ネットワーク越しのアクセスとレイアウト崩れがないかを確認するため |
| i-2 | 画面を指でタップし、`SELECT`から`'S4'`までCH1の全トークンをタップする（CH1と同じ順） | 画面の狭さでもトークンが押しにくくない・誤タップしない | スマホ幅でのタップ精度を確認するため |
| i-3 | 実行ボタンをタップし、行数予測で「3」をタップする | 予測ボタンが指で押しやすい大きさで表示され、正しく反応する | 小さいボタンが押し間違えやすくなっていないかを確認するため |
| i-4 | 正解後の結果パネル・NORA LOGを確認する | PC版と同じ内容が、横スクロールなしで読める | 縦長画面でのテキスト表示崩れがないかを確認するため |

| # | 何をするか | 何が見えるべきか | なぜ確認するのか |
