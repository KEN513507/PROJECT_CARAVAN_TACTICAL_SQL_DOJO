1. 開発背景とコア思想（Cognitive Engineering）

1.1 従来のモバイル学習における3大ペイン

Extraneous Cognitive Load（外在性認知負荷）の過多:

スキーマ（表構造）と問題文とクエリ入力欄を往復スクロールしなければならず、ワーキングメモリが枯渇する。

iPhoneの仮想キーボードが立ち上がると画面の50%以上が隠れ、Safariの16px未満自動ズームによって視界が破壊される。

Action Execution Cost（行動実行コスト）の増大:

スマホのソフトウェアキーボードで SELECT、FROM、大文字小文字、シングルクォート '、セミコロン ;、カンマ , を切り替えながら打つ作業は学習の本質ではなく、強烈な離脱要因となる。

Delayed Sensory Feedback（多感フィードバックの欠落）:

テキストの正誤表示だけではドーパミン分泌（強化学習）が起きない。タップ音、周波数を計算した正解チャイム、低域の警告音、触覚フィードバック（Haptics）が欠如している。

1.2 コア解決アプローチ

Single-Screen Zero-Scroll Layout: スクロール不要で「進捗」「表スキーマ」「問題」「クエリ結果」を1画面（100dvh）に収める。

Token-Based Construction System: キーボード入力を原則排除。トークンを指先1本でタップしてクエリを組み上げる。セミコロンやカンマ等の形式的構文エラーは正規化エンジンが自動吸収する。

Evaluation-Order-First Mental Model: SQLの構文順（SELECT → FROM）ではなく、内部評価順序（FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY）をステップ実行で体感させる。

Synthesized Multi-Sensory Loop: 外部音声ファイル（mp3等）への通信依存をゼロにし、ブラウザ内蔵の Web Audio API でリアルタイムにミリ秒単位の音響フィードバックを生成する。

2.2 機能要件（Functional Requirements）

FR-01: 常時視認スキーマ・ビューワー（Sticky Multi-Schema View）

画面最上部に、現在解いている問題で参照するテーブル構造（列名・実データ複数行）を常時ピン留め。

複数テーブル結合問題（JOIN）の場合は、タブ切り替えまたはスプリット表示により、1タップ以内で相互のキー列（主キー/外部キー）を視認可能にする。

FR-02: ノン・キーボード・トークンパット（Tactile Token Assist Pad）

設問に必要な句（SELECT, FROM, WHERE 等）、列名（商品番号, 単価 等）、演算子（= , >=, SUM(...) 等）を色分けした独立ボタンとして配置。

トークンタップ時に、前後の文脈を判定して半角スペースやカンマ（,）を自動補完。

サブ操作として「カンマ手動挿入」「1語削除（Undo）」「改行」「全クリア」を独立配置。

FR-03: 構文柔軟化 & セミコロン自動無害化エンジン（Query Normalizer）

セミコロン（;）の有無は基本情報技術者試験の本質ではないため、末尾のセミコロンは完全無視・自動吸収。

全角スペース、全角カンマ、余分な連続空白、改行の差異を正規化（Normalize）し、本質的なロジックのみを論理検証。

FR-04: 評価順序ステップ・エクスプローラー（Order-of-Execution Stepper）

クエリ実行前に「評価順を確認」ボタンを押すことで、DBエンジンがどう動くかを5段階のステップカードで解説。

FROM / JOIN: どの表とどの表を合体させたか

WHERE: どの行がふるい落とされたか

GROUP BY: どの列を軸に山分けされたか

HAVING: どの集計グループが落とされたか

SELECT: どの列に名札を付けて取り出したか

FR-05: Web Audio API による合成音響エンジン（Zero-Latency Sound Engine）

外部音声ファイルのローディング遅延やミュート制限を回避し、オシレーターで波形を動的合成。

タップ音: 高周波（600Hz）正弦波（Sine）、50msの超短減衰クリック音。

正解音: アルペジオ和音（C5: 523Hz → E5: 659Hz → G5: 784Hz → C6: 1046Hz）の開放感ある三角波（Triangle）。

エラー音: 低周波（140Hz → 100Hz）ノコギリ波（Sawtooth）、250msの警告ブザー音。

キャラバン制覇ファンファーレ: 祝祭的な長音ハーモニー。

FR-06: キャラバン進行 & タイムプレッシャーXPシステム

5問1セットの「キャラバン（道程）」として視覚化。

各設問に制限時間（45秒〜60秒）を設定。

1秒ごとのカウントダウンとともに、残り時間に応じたXPボーナスを付与（即答するほど高得点）。

失敗しても即座に「模範構造」を展開し、再挑戦を容易にする。

4. フロントエンド・ロジック詳細仕様

4.1 SQL正規化・検証アルゴリズム

ユーザーがトークンをタップして構築した文字列を、以下のパイプラインで正規化してからバリデーション関数に渡す。

function cleanSQL(rawSql) {
  return rawSql
    .toUpperCase()
    .replace(/;/g, '')              // セミコロンを完全除去（無害化）
    .replace(/[、，]/g, ',')        // 全角記号の吸収
    .replace(/\s*,\s*/g, ', ')      // カンマ周りの空白正規化
    .replace(/\s*=\s*/g, ' = ')     // 等号周りの正規化
    .replace(/\s*>=\s*/g, ' >= ')   // 不等号周りの正規化
    .replace(/\s+/g, ' ')           // 連続する改行・空白を単一スペース化
    .trim();
}


4.2 Web Audio API 実装定義

class SoundEngine {
  constructor() {
    this.ctx = null;
  }
  init() {
    if (!this.ctx) {
      const AudioCtx = window.AudioContext || window.webkitAudioContext;
      if (AudioCtx) this.ctx = new AudioCtx();
    }
    if (this.ctx && this.ctx.state === 'suspended') {
      this.ctx.resume();
    }
  }
  playTap() {
    this.init();
    if (!this.ctx) return;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.type = 'sine';
    osc.frequency.setValueAtTime(600, this.ctx.currentTime);
    gain.gain.setValueAtTime(0.04, this.ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.001, this.ctx.currentTime + 0.05);
    osc.start();
    osc.stop(this.ctx.currentTime + 0.05);
  }
  playSuccess() {
    this.init();
    if (!this.ctx) return;
    const now = this.ctx.currentTime;
    const notes = [523.25, 659.25, 783.99, 1046.50]; // C5, E5, G5, C6
    notes.forEach((freq, idx) => {
      const osc = this.ctx.createOscillator();
      const gain = this.ctx.createGain();
      osc.connect(gain);
      gain.connect(this.ctx.destination);
      osc.type = 'triangle';
      osc.frequency.setValueAtTime(freq, now + idx * 0.07);
      gain.gain.setValueAtTime(0.08, now + idx * 0.07);
      gain.gain.exponentialRampToValueAtTime(0.001, now + idx * 0.07 + 0.22);
      osc.start(now + idx * 0.07);
      osc.stop(now + idx * 0.07 + 0.22);
    });
  }
  playError() {
    this.init();
    if (!this.ctx) return;
    const now = this.ctx.currentTime;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.type = 'sawtooth';
    osc.frequency.setValueAtTime(140, now);
    osc.frequency.linearRampToValueAtTime(90, now + 0.22);
    gain.gain.setValueAtTime(0.12, now);
    gain.gain.exponentialRampToValueAtTime(0.001, now + 0.22);
    osc.start(now);
    osc.stop(now + 0.22);
  }
}
